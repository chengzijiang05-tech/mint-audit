# E9：第二代正统基线（TR 统计量 + IAAFT surrogate 校准）

## 定位

定位：Theiler 程序对时间不可逆问题的标准答案是"TR 敏感统计量 + AAFT/IAAFT surrogate 校准 p 值"。E9 补齐这一最强形态的第二代基线，使三代对决在公平口径下成立。

## 统计量族（计量文献既定定义）

| 统计量 | 定义 | 来源 |
|---|---|---|
| L | 杠杆相关 L(k)=E[r_t r²_{t+k}]/E[r²]² − E[r²_t r_{t+k}]/E[r²]²，读数 = mean_{k≤K} \|L(k)\|（无向） | Bouchaud et al. 2001 |
| Ldir | 同上，mean_k L(k)（有向） | 同上 |
| CCK | TR(k)=E[r_t r²_{t+k}] − E[r²_t r_{t+k}] 的 k 加权和（经验协方差二次型） | Chen-Chou-Kuan 2000 |
| bispec | 非线性相位耦合质量（bicoherence 平方和） | Hinich 1982 |

## 校准（第二代精髓，免阈值、免训练）

对被检窗口 x 生成 B=99 条 IAAFT surrogate（保边际保谱、毁相位），p = (1 + #{T(surr) ≥ T(x)}) / (B+1)，双侧取 min(p_hi, p_lo)。判伪造 = p ≥ α（α=0.05）：统计量落在自身 surrogate 分布内（不拒绝"时间可逆 H0"）即无箭头证据，判伪造；p < α 为显著偏离 surrogate，判真实。

> 实现口径：双侧 p 取 min(p_hi, p_lo)，上限即 0.5；判伪造条件为 p ≥ α（α=0.05）。种子以家族索引确定性映射生成，全程可复现。

## 结果解读

1. **第二代在旧战场有效**：对变换族 N4/N5 与 QuantGAN（N7b），校准后的 TR 统计量达到 AUC 0.77–0.91，这证明基线实现是强的、公平的， straw-man 指控不成立。
2. **第二代在 LLM 战场失明**：对真实 LLM 锻造（N7a），四个 TR 统计量 AUC 全部落在 0.51–0.70，最优 Ldir 仅 0.696，bispec 近乎抛硬币（0.511）。LLM 在文本域学到的数值续写不产生 surrogate 校准能察觉的时间不可逆箭头。
3. **第二代对模型化波动同样乏力**：对"正统"计量的 GJR-EGARCH（N8），AUC 仅 0.60–0.67。模型化波动率的时变二阶结构使固定窗 TR 统计量与 surrogate 零假设同时失真。
4. **校准 FPR 失控**：四个统计量的标称 α=0.05 下经验 FPR 达 0.25–0.57，IAAFT 校准在真实金融窗上严重过宽，这本身即第二代方法在非平稳数据上的结构性缺陷证据。

## 结论

E9 与 E7 合并构成论文最强论证链：第二代方法（含其最强形态 Theiler 程序）在旧战场（变换族、GAN）保持有效，却在论文标题指向的新战场（真实 LLM 锻造、模型化波动）集体失明（AUC 0.51–0.70），而 MINT 在同一批敌手上 AUC 0.82–0.92、FPR 7.1%、认证零误证。三代对决成为可复现的测量。
