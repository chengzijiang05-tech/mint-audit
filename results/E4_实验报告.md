# E4 跨市场转移实验报告：有效性的无条件转移与功效的条件转移

日期：2026-08-20
脚本：`MINT/exp/e4_transfer.py`（完整版 epochs=250，717.9 s；冒烟版 39.7 s 先行验证管道）
产出：`results/e4_transfer.json`、`figures/fig_e4_transfer.pdf`

## 一、目标与命题

验证 H4 与 T4（MINT 整体研究方案 §T4、实验 E4）：

- **H4**：冻结编码器 + 本地轨道校准的跨市场 FPR ≤ 0.15（对照：现稿经典阈值搬运 0.80 灾难）；FAIL 线为 > 0.30。
- **T4(i)**：e 值有效性不依赖目标市场任何分布假设，轨道归一化逐市场进行，有效性由可交换性结构保证（**有效性无条件转移**）。
- **T4(ii)**：功效保留取决于目标市场不变量律与训练算子混合的 TV 距离 δ，功效随 δ 条件转移。

设计：CN（沪深300）/ US（SPY）/ HK（恒生+国企）三市场，R6 协议三层切分（参考库/cal/测试数据不相交），3×3 转移矩阵。对角线 = 本地全流程参照（"全本地重训"上界口径）；非对角 = 跨市场。三策略：S1 阈值搬运（源 cal q95 直接作用于分数）、S2 冻结编码器 + 目标窗本地轨道 e 值（双向：W_cert 认证真实 / W_flag 判伪造，E_VAL=1/α=20，Markov 水平）。伪造族 N1–N5 与 R6 同族同种子（2000+wi·10+fi），经典对照数字直接引自归档 `r6_cross_market.json`（同协议）。

三个决定性事实：

1. **S2 FPR = 0.0（九格全零）**，H4 以最大裕度通过（阈值 0.15，FAIL 线 0.30）。
2. **零假设水平 = 0.0（九格全零 + 系综十格全零，19/19）**，T4(i) 有效性无条件转移成立。
3. **flag 功效跨市场归零**（非对角 macro flag recall 全 0），但**认证功效按 δ 条件存活**（见第四节）。

Wilson 95% CI（诚实披露）：CN/US 格 n=10，FPR=0 的上界 0.278；HK 格 n=20，上界 0.161；零假设水平 n=20/40，上界 0.161/0.088。点估计全零但样本量决定了上界宽度，论文中需以 CI 口径陈述。

*经典 recall 在 FPR 0.75–0.80 下无意义（拦截一切）；**经典 FPR=0 是功率坍塌假象（recall 0.41–0.46，N5 低至 0.05）。

R6 的核心病理，分数尺度市场局部性（低阈值源爆炸、高阈值源功率死亡），在 MINT 下被两层机制瓦解：

- **S1 层（边际歼灭的副产品）**：rank→Gaussianize 预处理使编码器分数尺度跨市场可比，即使最粗暴的阈值搬运，FPR 也只有 0.0–0.1（经典同协议 0.60–0.80）。
- **S2 层（协议本质）**：轨道 e 值完全不需要目标市场的 clean 标定数据（逐窗生成自身轨道），校准随窗口走，FPR 九格全零。**"表示共享，校准本地"从经验规则（现稿协议规则 1）升格为定理级分解**，这正是 T4 的论文角色。

## 四、T4(ii) 验证：δ 条件转移

δ̂ 在编码器分数空间估计（真实窗 vs 轨道成员分数分布的 TV 距离，8 分箱；AUC = P(s_real > s_orbit)）：

- **Spearman(δTV, 认证率) = 0.829，p = 0.0057**，功效条件转移的理论预测得到九格强支持。
- 结构清晰可读：δTV=1.0 的两格（US→US、HK→HK，真实窗与轨道完全分离）认证率 1.0；δTV 最低的 US→HK（0.45）认证率 0；HK→US δTV=0.92 → 认证 0.6。
- Spearman(δTV, flag recall) 无法计算（flag recall 九格全 0 无方差），T4(ii) 在认证轴验证，flag 轴转移后失效。

### 认证轴的决策穿透力（真实窗认证率 − 伪造窗认证率）

| 单元 | 真实窗认证 | 伪造窗认证（N1/N2/N3/N4/N5） | 穿透力 |
|---|---|---|---|
| US→US | 1.00 | 1.0 / 0 / 0 / 0 / 0 | **0.80** |
| HK→HK | 1.00 | 1.0 / 0 / 0 / 0 / 0 | **0.80** |
| HK→US | 0.60 | 0.6 / 0 / 0.4 / 0 / 0 | 0.40 |
| CN→CN | 0.50 | 0.5 / 0 / 0 / 0 / 0 | 0.40 |
| HK→CN | 0.40 | 0.4 / 0 / 0 / 0 / 0 | 0.32 |
| CN→US | 0.20 | 0.1 / 0 / 0 / 0 / 0 | 0.18 |
| CN→HK / US→CN / US→HK | 0.00 | 全 0 | 0.00 |

两个结构性发现：

1. **N2–N5 伪造窗在所有九格（含对角线）几乎从不被认证为真实**（唯一例外 HK→US 的 N3 认证 0.4）。认证协议下"不能认证 = 送人工复核"，故 N2–N5 的复核通道召回接近 1.0，转移后检测语义从"flag 检出"迁移为"拒绝认证"，且该通道无条件可用。
2. **N1（数值置换）是认证轴的系统性盲点**：其认证率与真实窗认证率几乎重合（0.5/0.1/0.4/0.6/1.0 对 0.5/0.2/0.4/0.6/1.0），iid 置换窗在编码器眼中与真实窗同质。这与 E2 主实验中 N1 recall 全线最低（A0/A4/A5b 均 0–0.25）互为印证，五算子轨道负样本训练覆盖了 N2（时间倒置）盲区，但 N1 仍穿透认证层。论文须如实披露：MINT 的认证保证对 N1 类"边际保真、依赖结构歼灭"伪造不设防（其轨道与窗口自身可交换，e 值结构上无法区分）。

## 七、局限与论文写作注意

1. **样本量**：每格 clean n=10（HK 20），FPR=0 的 Wilson 上界 0.16–0.28；结论以"点估计全零 + CI 口径"陈述，避免绝对化。
2. **flag 功效的市场局部性属于特性，表述须有明确边界**：论文应写"有效性无条件、认证功效条件、flag 功效市场局部"，三者分明；不可笼统宣称"检测力跨市场保留"。
3. **N1 盲点**须在 E4 与 E2 两处一致披露，并归因于 e 值的结构性交换（N1 窗与其轨道同分布），这与 T1 的保证语义一致（保证对象是 FPR；对各伪造族的功效属于另一维度）。
4. **协议偏差披露**：HK 训练 span 取测试前历史（数据太短，偏离 E2 的 train<cal 顺序）；HK cal 层（HSCEI 12–19）与测试层在 HSCEI 内日历部分重叠（继承 R6 协议，仅影响 S1 的 HK→HK 格）。
5. δ̂ 为一维分数空间投影估计（TV 8 分箱），是 δ 的下界性代理；论文理论节应说明投影不放大 TV。
